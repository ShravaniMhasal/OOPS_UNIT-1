Brief description: 
<br>
1. Basic Variable Declaration & Output:
<br>
Declares simple variables (roll number, grade, fee) of different data types (int, char, float) and prints them using cout. Demonstrates basic input/output and variable types in C++.
<br>
2. If-Else Condition (Pass/Fail):
<br>
Takes a student's marks and uses an if-else statement to check whether the marks are above or below the passing threshold (40), printing "Pass" or "Fail" accordingly. Demonstrates conditional statements.
<br>
3. Arrays & Loops:
<br>
Stores marks of 5 students in an array, uses a for loop to print each student's marks, and calculates the total and average marks. Demonstrates arrays, loops, and basic calculations.
<br>
4. Function Declaration & Definition:
<br>
Declares a function add() before main(), calls it inside main() to add two numbers, and defines the function after main(). Demonstrates function prototypes, function calls, and function definitions.
<br>
5. Class with Member Function:
<br>
Creates a Student class with name and age as data members and a show() function to display them. An object is created in main() and its data is set and displayed. Demonstrates basic OOP concepts — classes and objects.
<br>
6. Constructor & Destructor:
<br>
Creates a Demo class with a constructor (runs when object is created) and destructor (runs when object is destroyed), showing the automatic calling order of both. Demonstrates constructor/destructor concepts.
<br>
7. Static Data Member:
<br>
Creates a Student class with a static variable count that increases every time a new object is created, shared across all objects of the class. Demonstrates static members and their behavior.
<br>
8. Private Member, Inline Function & Friend Function:
<br>
Creates a Test class with a private data member, an inline function to access it normally, and a friend function that can access the private member from outside the class. Demonstrates encapsulation, inline functions, and friend functions.
